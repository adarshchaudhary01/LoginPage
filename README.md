# Modern Login Page

A clean, responsive, and minimalist Login Page built using pure **HTML5** and **CSS3**. Designed with modern UI standards, subtle animations, and full mobile responsiveness.

---

## Features

* **Responsive Design:** Optimized for desktops, tablets, and mobile devices.
* **Modern UI:** Clean typography, glassmorphism/card layout, and smooth focus states.
* **Form Structure:** Accessible input fields for username/email and password.
* **Interactive Elements:** Hover and focus effects on input fields and action buttons.
* **Lightweight:** Zero external libraries or heavy dependencies—pure native web technologies.
